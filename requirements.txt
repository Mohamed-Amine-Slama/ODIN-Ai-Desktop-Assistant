# All of Jarvis's dependencies, in one file: pip install -r requirements.txt
#
# Sections below that say "optional" mean the corresponding skill/feature
# degrades gracefully without it (falls back, or reports what's missing)
# rather than crashing Jarvis as a whole — see each section's own comment.

# --- Core: everything Jarvis needs to run in text mode ----------------------
openai>=1.0.0
python-dotenv>=1.0.0
psutil>=5.9.0
requests>=2.31.0
plyer>=2.1.0

# Native Anthropic path (MODEL names a Claude, or BASE_URL is empty) and
# Amazon Bedrock (MODEL=bedrock/..., core/brain.py's _BEDROCK_PREFIX): both
# optional in the sense that Jarvis runs fine on any OpenAI-compatible
# endpoint without this, but importing anthropic raises a clear error at
# startup instead of a vague one if a Claude/Bedrock MODEL is configured
# without it installed. The `bedrock` extra additionally pulls in boto3,
# which AnthropicBedrock needs to talk to Bedrock's runtime API — auth is
# an AWS Bedrock API key (AWS_BEARER_TOKEN_BEDROCK in .env), which boto3
# picks up from the environment on its own.
anthropic[bedrock]>=0.68.0

# Screen awareness (see_screen) and clipboard
mss>=9.0.1
pillow>=10.0.0
pyperclip>=1.8.2

# read_pdf: optional. Without it, the skill reports what's missing instead
# of failing to start.
pdfplumber>=0.11.0

# web_search / deep_learn's search step. No API key, no signup, no billing —
# unlike every LLM-provider-hosted search option, this needs nothing beyond
# the package itself.
ddgs>=9.0.0

# Windows-only: system volume control
pycaw>=20240210; sys_platform == "win32"
comtypes>=1.2.0; sys_platform == "win32"

# Offline TTS fallback (the main voice pipeline is in the Voice section below)
pyttsx3>=2.90

# Synthetic keyboard and mouse (type_text / press_keys / click). Without this
# those skills degrade to a "not installed" message rather than crashing.
pyautogui>=0.9.54

# Hand-gesture cursor control (core/gesture.py, ENABLE_GESTURE_CONTROL):
# optional. Without these, hand_control degrades to a "not installed"
# message rather than crashing. Reuses pyautogui above for the actual
# cursor moves/clicks. mediapipe's hand-landmark model (~8MB) isn't bundled
# with the package — it's downloaded once to data/models/ on first use.
opencv-python>=4.9.0
mediapipe>=0.10.14

# Desktop HUD. `keyboard` is only for the global summon hotkey — everything
# else works without it.
PyQt6>=6.6.0
keyboard>=0.13.5; sys_platform == "win32"

# Discord bridge (core/discord_channel.py, DISCORD_BOT_TOKEN): optional.
# Discord's bot Gateway is a persistent websocket protocol (handshake,
# heartbeats, reconnect/resume), unlike Telegram's plain long-poll REST API —
# genuinely complex enough to be worth this library instead of hand-rolling
# it. Without it, the bridge just stays off and logs why.
discord.py>=2.3.0

# Tests
pytest>=8.0.0

# --- HUD: optional thermal/GPU sensors (see ODIN-HUD.md §7.4) ---------------
# Neither package is required — without them, the HUD's thermal readouts
# render "--" instead of a fabricated value, per the HUD's own rule against
# inventing numbers a sensor didn't actually report.

# GPU temp / load / VRAM. NVIDIA only. nvidia-ml-py is NVIDIA's official
# package for the `pynvml` module — the standalone `pynvml` package on PyPI
# is a deprecated third-party shim that now warns on import.
nvidia-ml-py>=12.535.0; sys_platform == "win32"

# CPU temp / fan RPM. Needs LibreHardwareMonitor running with its WMI
# provider enabled — this package only talks to it, it doesn't ship it.
wmi>=1.5.1; sys_platform == "win32"

# --- Email and calendar: optional (read_email, send_email, list_events, ----
# create_event, delete_event). Jarvis runs fine without any of this — the
# skills just stay unregistered until an account is connected (see README
# section on email/calendar setup).

# Google: Gmail + Calendar APIs, OAuth via a Desktop-app client you register
# yourself at console.cloud.google.com.
google-auth-oauthlib>=1.2.0
google-api-python-client>=2.100.0

# Microsoft: Mail + Calendar via Graph, OAuth via a public-client app you
# register yourself at portal.azure.com. No separate Graph SDK needed —
# Graph is called directly over HTTPS with `requests`, already a core dep.
msal>=1.28.0

# --- RAG: optional local knowledge base for deep_learn, and semantic -------
# search for the memory skill's recall (core/memory_index.py) — both share
# one embedding model via core/embeddings.py. sentence-transformers pulls in
# torch, which is a large install (hundreds of MB to a couple GB depending on
# platform). Jarvis runs fine without any of this — deep_learn just reports
# what's missing, and memory recall quietly falls back to plain-text search.

# Local embeddings — no API key, no per-chunk cost, works offline after the
# first run (which downloads the ~90MB all-MiniLM-L6-v2 model). Uses an
# NVIDIA GPU automatically if the installed torch build supports CUDA — pip's
# default torch wheel is CPU-only on Windows, so for GPU acceleration here
# install torch from https://pytorch.org/get-started/locally/ *before*
# installing this file (pip won't downgrade an already-satisfied dependency).
sentence-transformers>=3.0.0

# Local vector store, persisted under data/knowledge_db and data/memory_db.
chromadb>=0.5.0

# --- Voice: optional hands-free pipeline ------------------------------------
# Pulls ~1GB of ML wheels and model weights. Jarvis runs fine in text mode
# without any of it.

# Audio capture. sounddevice ships working Windows wheels, unlike PyAudio.
sounddevice>=0.4.6
numpy>=1.24.0

# Wake trigger: reuses faster-whisper below to listen for the assistant's
# name + "wake up" (core/wake.py) — no separate model or API key needed.

# Speech-to-text: local Whisper. Offline, accurate, and your audio never
# leaves the machine (the old SpeechRecognition backend posted it to Google).
# Uses an NVIDIA GPU automatically (STT_DEVICE=auto in .env) — on Windows
# that additionally needs the CUDA 12 runtime + cuDNN 9 on PATH, or just
# `pip install nvidia-cublas-cu12 nvidia-cudnn-cu12` alongside this file.
faster-whisper>=1.0.0

# Text-to-speech: Edge neural voices (free, no key) + playback.
edge-tts>=6.1.0
pygame>=2.5.0
